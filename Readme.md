
# Arctic Fuse 3 Cine [![License](https://img.shields.io/badge/license-CC--NC--SA%204.0-green)](http://creativecommons.org/licenses/by-nc-sa/4.0/)

**Arctic Fuse 3 Cine** is a home-cinema modification of **Arctic Fuse 3** (originally created by [jurialmunkey](https://github.com/jurialmunkey)), modded by [paradigm_city](https://github.com/paradigm-city).

### Distinctions & Enhancements
- **Calibrated for Large Displays & Cinema**: Scaled-down typography (~20% reduction) and tighter geometric proportions prevent UI bloat on large screens (65"+, 85"+), ultrawide formats (21:9), and home cinema projectors.
- **Condensed Typography**: Integrated Roboto Condensed fontset (Light, Regular, Bold) for higher information density and elegant readability.
- **Streamlined Micro-OSD**: Compact 64px circular action controls, 10px progress bar, custom seek slider nib, and optimized spacing.
- **Technical Audio & File Inspection**: Rich music info dialog displaying file path navigation, audio codec, bitrate (kbps), sample rate (Hz), duration, BPM, file size, play counts, and ratings.
- **Persistent Header Overlay**: Subtle and consistent time, date, and weather display.
